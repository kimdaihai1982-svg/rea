5. CÁC LỆNH QUẢN LÝ DOCKER (Gõ trên màn hình đen SSH)
--------------------------------------------------------------------------------
- Vào thư mục dự án      : cd /opt/stack
- Xem trạng thái các dịch vụ: sudo docker compose ps
- Khởi động lại tất cả   : sudo docker compose restart
- Xem log của Tunnel     : sudo docker logs cloudflared --tail 20
- Xem log Web           : sudo docker logs web --tail 20

6. TEST MQTT VÀ LƯU VÀO DATABASE (PHP WORKER)
--------------------------------------------------------------------------------
Để PHP hứng dữ liệu MQTT lưu vào Database, file worker cần chạy ngầm 24/7.
Nếu máy chủ khởi động lại, gõ lệnh sau để bật lại Worker:

sudo docker exec -d web php /var/www/html/worker.php > /dev/null 2>&1 &

Để test gửi tin nhắn từ Web (không cần cài phần mềm):
1. Vào trình duyệt mở: https://maychu247.uk/test_mqtt.php
2. Đợi 2 giây, mở https://adminer.maychu247.uk -> bảng sensor_logs -> Xem dữ liệu.

Định dạng dữ liệu MQTT (JSON) cần gửi:
Topic: home/sensor/data
Payload: {"device_id": "ESP32_01", "temp": 30.5, "hum": 70}
